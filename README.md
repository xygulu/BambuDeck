# BambuDeck

拓竹(Bambu Lab)打印机 + 摄像头的多平台监控与控制套件。一块屏幕看所有打印机和摄像头,
手机/平板通过网页远程查看和控制;支持一键换盘、远程派单、AI 视觉值守。

- **客户端模式**:App 直连打印机与摄像头,无需服务端
- **Hub 服务端模式**:常驻服务聚合多打印机/多摄像头,手机/平板开网页即用,支持公网远程访问
- **客户端**:macOS、Android、Windows(Releases 可下载);iOS 等其它设备走网页端;
  Windows 也可部署 Hub 服务端常驻(见下)

> 本项目由 [BambuHelper](../BambuHelper)(ESP32 小屏固件)改造而来,是全新的独立项目。

## 功能一览

**看打印**
- 首页一屏看所有打印机:进度、喷嘴/热床温度、耗材(AMS)、剩余时间,实时刷新
- 机器报错自动翻译:报错码对照拓竹官方错误库(2500+ 条),直接给出人话说明
- 打印完成/失败/出问题时,电脑收到系统通知(目前 macOS)

**控打印**
- 在卡片上直接 暂停 / 恢复 / 停止;进详情页可调打印速度、开关腔灯
- **一键换盘**:打印机空闲时点一下,自动上传换盘程序并派单,打完自动把成品震落、
  换上新料(需自行安装换盘机构)
- **远程派单**:把打印任务发给云账号名下的打印机;云模式的机器由本机的
  Bambu Connect 自动代为操作,你不用碰 Connect 窗口

**看摄像头**
- 打印机自带摄像头直接开(A1/A1 mini/P1 系列、X1/P1S 等按机型自动适配)
- 第三方 RTSP 摄像头:手填标准 RTSP 地址就能看,画面链路不挑品牌;局域网扫描
  自动发现、主/子码流一键切换,已按各品牌官方路径适配海康、大华、萤石、TP-Link、
  Reolink 的地址格式。**除萤石经真机实测外,其余品牌按官方协议实现、未逐一真机
  验证**,遇到不适配欢迎提 issue 反馈
- 萤石可云端一键导入:填开放平台的 AppKey/AppSecret,账号名下的设备自动进列表,
  并配对出局域网地址
- 摄像头和打印机自由绑定;多路画面自动拼成一墙,点一下放大单个画面
- 云台控制:标准 ONVIF 摄像头通用;萤石设备即使关了 ONVIF 也能控
  (走海康 8000 端口私有协议)

**AI 值守(可选)**
- 接一个视觉大模型(OpenAI/Anthropic 兼容接口都行),它定时看打印画面:
  发现异常(空打、堵料等)给你推送,也可以让它直接帮你暂停打印机

**手机/平板用**
- 浏览器打开就是完整控制台:看状态、看画面、暂停/换盘,竖屏自适应
- 拓竹账号在网页上登录即可,打印机清单自动从云端同步进来
- 配合 Cloudflare 隧道,出门在外也能看

**保持最新**
- 自动检查新版本(Hub 每 6 小时、App 启动后及每 12 小时),发现新版会提醒你;
  要不要装由你确认

## 部署

### 方式一:客户端直连(最简单)

1. 安装并打开 App(上表 apk / macos.zip / windows.zip)
2. 右下角「添加打印机」:
   - **局域网直连**:填打印机 IP + 序列号 + 局域网访问码(打印机屏幕:设置 → 局域网 可查)
   - **拓竹云端**:账号登录(手机号/邮箱 + 密码,或验证码),打印机自动同步进来
3. 完事。摄像头在「摄像头」页添加(RTSP 地址,或直接开打印机自带摄像头)

### 方式二:Hub 服务端(推荐给盒子/NAS 常驻)

App 关了监控也不停,手机随时开网页看:

1. 下载 `deck-hub-windows.zip` 解压到任意目录(如 `C:\deck-hub-windows`),双击
   `install-service.bat`:注册计划任务开机自启,自动生成随机访问口令
2. 浏览器开 `http://<本机IP>:8787`,输入口令(在包目录的 `config\hub.json` 里
   `settings.hubToken`)进入
3. 网页右上「账号」登录拓竹账号 → 打印机清单自动同步;再添加摄像头即可
4. **公网访问(可选)**:装 [cloudflared](https://developers.cloudflare.com/cloudflare/one-connections/tunnels/)
   把隧道指到 `http://localhost:8787`,绑定自己的域名,手机在外网直接开

macOS 用户:直接用 App 内置的「网页访问」开关(设置里)即可起同样的网页端。

## 使用前提(重要)

| 你想做什么 | 需要先准备 |
|---|---|
| 看状态/温度/进度 | 只需打印机联网:局域网模式填 IP+序列号+访问码(跨网段也能自动发现);或直接登录拓竹云账号 |
| 局域网直发打印/换盘 | 打印机开**开发者模式**:设置 → 网络 → 仅局域网模式 → 开发者模式 → 启用后重启。2025 年后的固件对未签名打印指令一律拒绝,不开就只能走云 |
| 云模式打印/换盘/控制(开发者模式关) | 电脑上装 [Bambu Connect](https://bambulab.com/en/support/download) 并登录**同一拓竹账号**,之后全自动:macOS 需在 系统设置 → 隐私与安全性 → 辅助功能 里放行;Windows 部署包已内置,装完即用 |
| 接第三方摄像头 | 摄像头开启 RTSP;想控云台需 ONVIF(或萤石 + 开放 8000 端口) |
| AI 值守 | 任一 OpenAI/Anthropic 兼容的视觉接口。App 设置 → 视觉监控:填 Base URL + API Key + 模型名。例:Base URL `https://api.minimaxi.com/anthropic`,模型 `MiniMax-M3` |

打印/控制按打印机状态自动选择路径(局域网直发或 Bambu Connect 代操作),你不用关心细节;
ffmpeg(拉 RTSP 流用)Windows 包已内置,其它平台自带,无需安装。

## 日常使用

- **看**:首页打印机卡片实时刷新;「监控」页是打印机状态 + 相机墙的单屏组合大屏,
  适合电视/平板挂着
- **控**:卡片上直接暂停/恢复/停止;详情页调速度、开关腔灯;网页端同样能操作
- **换盘**:打印机空闲时点「一键换盘」,自动上传换盘程序并派单,打完自动换上新料
  (需自行安装换盘机构)
- **AI 值守**:设置 → 视觉监控 开启,选摄像头、设间隔;发现异常可推送,
  勾选「自动暂停」则直接暂停打印机

## 架构与核心实现(简)

- **两种形态**:客户端 App(Flutter,多端)直连设备;Hub 服务端是纯 Dart 编译的
  常驻二进制,聚合所有打印机/摄像头,把网页端提供给手机/平板。
- **打印机协议**:自研纯 Dart 协议包(`packages/bambu_protocol`)实现拓竹的
  MQTT 上报/控制与云端 API,不依赖官方 SDK;云端账号的打印机清单自动同步,
  缺 IP 的机器自动扫描发现。
- **控制路由**:打印机开了开发者模式就走局域网直发(秒回);没开则自动改走
  本机 Bambu Connect 界面自动化代操作,对你是透明的。
- **画面链路**:打印机自带摄像头走 MJPEG/RTSPS 直拉;第三方 RTSP 摄像头经
  ffmpeg 解流转 JPEG;网页端所有画面合走**单条 WebSocket**,手机 Safari
  也不受浏览器同源连接数限制。
- **AI 值守**:定时抓取画面帧 → 视觉大模型判读 → 推送通知,可选拍板自动暂停。
- **自更新**:对照 GitHub Releases 清单自动检查,下载件一律做完整性校验,
  Windows Hub 一键换装重启,装不上坏包。

## 版本更新机制

- 检查全自动:Hub 后台每 6 小时查一次 GitHub Releases,App 启动后 8 秒和每 12 小时各查一次
- 发现新版:网页顶部出常驻提示条(点「查看更新」进服务状态面板),App 弹「发现新版本」对话框
- **安装需人工确认**:
  - Android:对话框里点「下载并安装」(系统安装器接管)
  - Windows Hub:服务状态面板点「立即更新」,自动下载→校验→换装重启(几秒)
  - macOS/其它:给下载页链接,手动替换
- 下载件一律做完整性校验,不对就丢弃重来,不会装上坏包

## 进阶:独立网页服务(macOS)

Windows 用户用上面的部署包即可;macOS 想让网页端脱离 App 常驻(开机自启、
关掉 App 也不停),可以把 Hub 编译成独立服务跑 launchd。配置由 App 导出到
`~/.bambudeck/hub.json`(访问口令在 `settings.hubToken`),配置变更自动热重载;
独立服务接管 8787 端口时,记得把 App 内置的「网页访问」开关关掉,避免抢端口。
具体编译和自启配置见 [研发计划](docs/研发计划.md)。
